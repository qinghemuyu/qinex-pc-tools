QInEX-Link 后台性能说明
========================

一、程序已经自动完成的优化

1. 进程使用 Windows High 优先级（不会使用可能导致系统卡死的 Realtime）。
2. 关闭 Windows 对本进程的执行速度节流，避免被归入 EcoQoS。
3. Windows 11 下要求系统在窗口被遮挡或最小化时，继续尊重 1ms 定时器精度。
4. 输入捕获、帧发送线程使用实时线程优先级，并单独关闭线程级节流。
5. 串口链路、kmboxNET 网络输入线程提升线程优先级，并单独关闭线程级节流。
6. 后台 Raw Input 成批到达时保留每份报告，并按原始时间线逐拍发送。
7. 主窗口进入后台后停止无意义的高频动画；任务栏 Hub 使用低优先级线程。

上述设置启动时自动应用。主界面日志会显示“后台性能保护”是否全部成功。
设置失败不会阻止程序运行，但应按照下方项目检查系统环境。

二、程序无法代替用户修改的系统设置

1. Windows 设置 → 系统 → 电源和电池 → 电源模式：选择“最佳性能”。
2. 关闭 Windows“节电模式/电池节省程序”；笔记本接通电源。
3. 厂商控制中心（联想、华硕、戴尔等）选择“性能/狂暴”模式，不使用静音或省电模式。
4. 控制面板 → 电源选项 → 当前计划的高级设置 → USB 设置：
   将“USB 选择性暂停设置”设为“已禁用”。
5. 设备管理器 → 通用串行总线控制器/端口：
   找到 P4 所在 USB Hub 或 USB 串口设备，在“电源管理”中取消
   “允许计算机关闭此设备以节约电源”。没有“电源管理”页的设备可跳过。
6. 以管理员身份运行 QInEX-Link，避免全局键鼠 Hook 被权限更高的游戏隔离。

三、不建议进行的设置

1. 不要手动把进程改成“实时(Realtime)”优先级，可能造成鼠标无响应或系统假死。
2. 不要使用来历不明的 HPET、核心停放、系统计时器注册表优化脚本。
3. 不要同时运行多个键鼠 Hook、鼠标宏、输入重映射工具做对比测试。

四、仍然卡顿时如何判断

1. 看任务栏 Hub 中间的双通道条：左侧为 PC 生成，右侧为手机实际取走。
2. PC 生成频率下降或最大生成间隔接近 10ms：优先检查电源模式、节流和系统负载。
3. PC 生成正常但手机频率下降：检查 USB 数据线、手机接口、P4 固件和供电。
4. 健康状态变红：保存日志，检查校验错误、丢帧和串口发送截断提示。

说明：提高优先级只能减少 Windows 后台调度造成的延迟，无法消除 USB、串口、
手机系统或游戏本身产生的瓶颈。
