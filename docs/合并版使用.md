# Link 内置 PC 光标

QInEX-Link 现在直接包含完整的 Pointer 桌面模块。日常只运行 `QInEX-Link.exe`，无需另开 Pointer。顶部「设备连接」「光标设置」在同一主窗口内切换。两页依据官网视觉统一为墨绿渐黑底色、静态细网格、透明细边框分区和荧光绿操作按钮，P4 标识使用金色；主窗口按屏幕工作区与 DPI 调整大小。材质通过现有 Win32 绘制实现。

## 入口与操作

1. 「设备连接」集中显示串口、转发、回报率、链路统计和日志；「光标设置」显示设备、画面、校准和个性设置。自定义图片、快捷键、采集卡和融合输出均保留。Ctrl+Tab 也可切换这两个区域。
2. 首次按设备 → 画面 → 四角与中心检查 → 保存并使用完成设置。保存成功后返回 Link；接收和已启动的画面输出继续工作。
3. 新配置默认勾选「随上位机启动连接上次设备」，完成并保存设置后生效。旧配置继续尊重原来的启动选项，可在光标设置中修改。
4. 右键 Link 托盘 →「PC 光标与画面…」，可连接/断开光标设备、暂停/恢复显示，以及操作已配置的全屏、HUD 和范围校准。
5. 切回设备连接不会停止光标接收，也不会丢失未应用草稿。关闭主窗口会收起到托盘，接收和转发继续。托盘退出 Link 时统一结束光标、演示和采集，并释放端口。存在未保存光标修改时，先确认是否继续处理；取消退出不会断开会话。

串口转发与 UDP 光标接收仍是独立连接。连接串口不等于已收到光标；P4 的 VP 光标仍需配置电脑 IP、JSON v2 和接收端口，步骤见 [Pointer 使用说明](../qinex-pointer/使用说明.md)。光标设置不要求串口转发就绪；这不改变 Link 对实际转发的设备授权检查。

## 原设置迁移

退出旧版程序后，将旧 Link 的 `link.json` 和旧 Pointer 的 `pointer.ini`、`profiles/`、`custom_cursor.png`、`custom_cursor.ini`（存在时）复制到合并版 EXE 同目录。先备份目标目录里的同名文件，不覆盖唯一副本。程序不自动搜索其它安装目录，也不改写旧安装。

两个独立程序仍可从源码构建。合并版和独立 Pointer 同时接收同一 UDP 端口会出现占用提示，日常使用一份即可。合并版的快捷键优先控制自己的光标窗口，未初始化内置模块时保留与旧独立版协作的能力。

Android 手机工具仍由 `-AndroidTools` 显式启用，启用后也包含在 Link 的 EXE 中，入口在光标设置的手机工具页。默认桌面包与原默认 Pointer 一样不含该可选页，参见 [构建指南](构建指南.md)。

## 开发验证

`pointer_embedded_runtime` 在独立测试目录中验证真实父子窗口、隐藏初始化、无第二托盘、重复打开、真实本机 UDP 报文、隐藏设置后接收继续、状态清理、重复启停及端口释放。`link_embedded_ui` 验证同窗口切换、点击隔离、各功能页尺寸和 DPI 变化后的草稿保留，可传输出目录生成生产绘制函数的离屏预览。Android 模式的测试使用隔离数据目录。

桌面界面需要复核顶部切换、Ctrl+Tab、托盘菜单、各功能页、演示、关闭再打开、草稿退出提示。真实 P4 转发、输入独占、采集卡画面、混合 DPI 和触点校准仍需设备验收；构建和模拟器不能替代这些检查。
