# 测试与验收

## 自动测试

运行 `./build.ps1 -Test`，默认包含：

| CTest 用例 | 范围 |
| --- | --- |
| `link_protocol` | 生产编码器的 F6/F7/F8 固定字节向量、小端顺序、饱和、间隔量化、全抬报文及 PING |
| `link_background_capture` | 后台鼠标增强注册与标准回退、无 WM_INPUT 通知的主动读取、定时器回退、原始报告顺序、按钮释放、避免限频空转；不安装 Hook 或注入真实输入 |
| `pointer_core_behavior` | JSON 严格校验、部分更新、隐藏/保活、负坐标多屏、旋转镜像往返、裁剪和校准退化 |
| `pointer_capture_diagnostics` | 采集诊断统计和 HUD 数据语义 |
| `pointer_embedded_runtime` | 同进程窗口生命周期、单托盘、重复初始化、真实本机 UDP 接收、隐藏后继续、停止清理、端口释放 |
| `link_embedded_ui` | 真实父子窗口、各功能页尺寸、切页命中隔离、DPI 重建草稿保留、统一退出；不启动串口或键鼠捕获 |

启用 Android 工具后增加 `pointer_android_behavior`：进程参数、超时取消、依赖缓存修复、模拟设备发现、权限失败及备份恢复。默认测试不修改真实手机。

GitHub Actions 的 Windows 工作流执行默认桌面构建和上述测试；它不发布文件。完整版仍需按构建指南单独验证。自动化通过不代表已经验证真实设备时序或所有 ROM。

## 无硬件 Pointer 演示

最方便的方式是设备页内置的独立演示。也可以在 Pointer 配置本机来源 `127.0.0.1`、端口 6533，运行：

```powershell
.\build\all-desktop\qinex-pointer\Release\QInEX-Pointer-Simulator.exe --pattern grid --duration 10
```

模拟器还支持 `circle`、`still` 和单次 `--state`，详见 `--help`。连续模式退出时释放并隐藏；单次 `press` 需后续 `release` 或 `hide`。模拟器只发送光标状态，不代表手机真实触点。

## 真机验收

Link 至少检查持续移动、快速反向、键鼠同时按下、滚轮、共享/独占切换、紧急释放、断线重连和程序退出。分别记录输入频率、PC 生成和设备交付阶段，关注长间隔与丢失边沿。

### 后台鼠标接收

Link 的鼠标注册尝试 `RIDEV_INPUTSINK | 0x8000`，键盘保持标准 `RIDEV_INPUTSINK`。
`0x8000` 是未进入公开 Windows SDK 的兼容标志，线索来自 [Noverse 的独立研究](https://www.noverse.dev/docs/win-config/peripheral/mouse-values/#throttle-checks)。实现没有复制该研究的反编译代码，也不修改系统注册表、加载驱动或切换窗口焦点。注册失败时重试标准鼠标/键盘注册并记录回退；注册成功不等同于系统一定兑现完整频率。

验收时使用同一只鼠标持续移动，比较前台、后台、遮挡和最小化；最好用两个独立进程同时对照 `0x0100` 与 `0x8100` 注册，记录窗口实际焦点、每秒报告数及每批报告数。轮询次数不是鼠标回报率，软件发送档位也不是硬件回报率。该标志的行为需在目标 Windows 版本实测，不能由 mock 测试推断；系统升级后若退回限频，要保留标准输入能力并重新核实。

Pointer 检查多屏与混合 DPI、四角和中心、旋转/裁剪、来源切换与断流隐藏、自定义热点、采集卡模式枚举及重连、全屏退出与 Link 协同校准。真实采集卡不同格式和驱动需分别测试。

Android 工具检查所选手机身份、权限拒绝、首次备份、重复执行、部分失败恢复、无线配对和不同 ROM 的可用性。涉及手机设置或安装的操作应由使用者在准备好的设备上确认执行。
