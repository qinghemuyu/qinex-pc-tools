# Pointer UDP 协议

一个 UDP 数据报对应一个 UTF-8 JSON 对象，默认接收端口 6533；接收端可配置端口。格式通常称 JSON v2，目前没有必填 `version` 字段，也没有发送时间戳或序号。

```json
{"type":"move","nx":0.25,"ny":0.75,"show":true,"down":false}
```

| 字段/类型 | 规则 |
| --- | --- |
| `type` | 必填：`move`、`show`、`hide`、`heartbeat` |
| `nx/ny` | 0…1 的有限数值；首次建立位置需要完整坐标，后续 `move` 可部分更新 |
| `move.show` | 省略时为 true；没有有效位置时保持隐藏 |
| `move.down` | 省略时保留现有按下态；隐藏会清除按下外观 |
| `show` | 显示已有有效位置，不凭空建立位置 |
| `hide` | 隐藏、清除按下外观 |
| `heartbeat` | 只保活，不改变位置或恢复可见状态 |

报文最多 4096 字节。布尔值必须是 JSON 布尔类型；重复协议字段、非法 UTF-8、未知 `type`、非法扩展字段、越界数字和畸形 JSON 都被拒绝。额外字段允许存在，但仍检查语法与嵌套深度。

接收器按来源 IPv4 过滤，不绑定发送者临时 UDP 源端口。未指定来源时，应用会话锁定首个有效发送 IP；断流不会自动换绑其他设备。这是来源选择规则，不是加密身份认证。

接收队列上限 2048 条，显示延迟队列上限 4096 个完整状态。默认即时显示，可配置 0…2000ms 延迟；位置、显隐和按下态一同延后。默认断流 2000ms 后隐藏并清队列，超时应大于显示延迟加 500ms。

坐标链路为：输入位置 → 仿射校准 → 手机内容区域 → 裁剪 → 旋转/镜像 → 显示区域。Pointer 不重新积分 PC 鼠标位移。具体几何见 [项目说明](../../qinex-pointer/README.md)。

UDP 丢包、乱序与短促按下可能无法完整反映；延迟设置依据接收时间，不能精确自动对齐视频。普通指针位置不能代表宏、多指或独立触摸轨迹。使用 [模拟器](../测试与验收.md) 可验证本机接收和显示，手机真实触点需另验。
