# kmboxNET 接入范围

Link 包含可选的 kmboxNET UDP 服务端。第三方程序连接本机 Link，网络键鼠输入与物理捕获合流，随后经 UART 发给 P4。此功能不改变 Link 到 P4 的串口链路。

默认关闭，端口默认 6234；开启时默认只绑定 `127.0.0.1`。`link.json` 中的 `netLan=true` 会绑定所有网卡，将输入入口开放到局域网。仅在明确需要并具备网络隔离时使用。

结构与处理真相源为 `qinex-link/src/netserver.cpp`：16 字节小端头 `mac, rand, indexpts, cmd`；鼠标 payload 含 `button/x/y/wheel` 与扩展点数组，键盘 payload 含修饰键和键码。当前实现处理连接、鼠标移动与按钮、滚轮、键盘全状态、monitor、屏蔽/解除屏蔽等命令，部分路径合并为即时移动。

这里是针对当前工具的兼容实现，不承诺完整复刻其他设备的所有命令、曲线或时间行为。实际命令常量与长度校验以接收分支为准；新增命令应同时补字节样例、错误处理与集成测试。

MAC 在工具首次启用服务时生成并显示，用于协议匹配和 XXTEA 派生；该机制不应被当作可靠的网络身份认证。应用的回读与 mask 语义由本机捕获状态决定。默认自动测试尚未覆盖真实网络注入和 monitor 的完整链路。
