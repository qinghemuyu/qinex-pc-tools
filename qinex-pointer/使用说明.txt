QInEX Pointer 快速使用

支持 Windows 10 / 11 x64。完整解压后运行 QInEX-Pointer.exe。

左侧导航切换页面，底部可切换普通模式 / 二次元模式，点击“保存”记住选择。设置页面带有短过渡和悬停反馈；采集或全屏输出运行时自动停用动效，也遵循 Windows 的动画开关。

点击主窗口右上角 X 会隐藏到系统托盘，指针和已启动的采集／融合输出继续运行。点击托盘图标恢复窗口；彻底关闭请右键托盘图标，选择“退出程序”。托盘图标也可能在任务栏右下角的“显示隐藏的图标”中。隐藏窗口会保留未保存的修改，退出程序前仍需保存。

1. “设备”页选择 P4 板子（单机 / 上位机直驱）并复制电脑地址。在板载页“网络 → VP 光标（PC / App）”启用 VP 光标，在“高级”中填入电脑 IP，关闭“兼容旧版 App”和“自动发现接收端”。S3 在本机 QInEX 开启 JSON v2 指针后连接。
2. 采集卡：在“画面”页选择采集卡、规格和输出显示器，点击“启动全屏”。
3. 视频融合器：选择“纯色背景全屏（融合器）”、输出显示器及绿幕/蓝幕/黑场/自定义背景，点击“启动融合输出”。电脑只输出纯色和光标，手机 HDMI 走融合器另一路输入，由融合器完成色键合成；此模式不占用采集卡。
4. 两种全屏底部 HUD 默认显示。采集模式显示接收 / 画面变化 FPS、重复采样比例、新视频呈现 / 重绘 FPS、软件耗时、帧间隔与时间戳异常；融合模式显示 Present、输出刷新率和指针数据。默认按 F7 显隐 HUD。
5. 默认按 F8 快捷校准光标范围：框内拖动可平移，拖边缘或四角可缩放，Enter 应用，Esc 取消。融合模式请对照融合器最终画面调整。
6. 默认按 F11 或 Esc 返回设置，也可使用右键菜单或托盘。设置页的“自定义快捷键”可分别修改暂停、HUD、范围校准和退出全屏；Esc 和固定后台逃生键 Ctrl+Alt+F12 始终可退出。上位机直驱模式独占输入时，QInEX-Link v0.1.13+ 会读取并放行当前自定义绑定，包含 Ctrl+Alt+Q 的组合始终用于紧急释放。
7. 融合 HUD 会进入色键信号；需要干净纯色背景时，使用当前 HUD 快捷键（默认 F7）隐藏。暂停指针后纯色背景继续输出。
8. 采集画面快捷校准后仍有局部偏差，再到“校准”页进行九点取样。截图完成后点击真实触点，再确认记录。

光标外观：设置页可选箭头、圆点、十字、圆环、涟漪、锁定框、轨迹或自定义图片，大小 12～144 像素。点击“选择 / 标定图片”，拖动十字设置图片热点，滚轮可放大微调；透明 PNG 效果最佳。在编辑器点“保存并应用”会立即写入图片和热点；当前样式、大小和颜色仍需点主页“保存”，才会在下次启动时恢复。

上位机直驱模式：自定义快捷键请配套 QInEX-Link v0.1.13 或更高版本。旧版只认识默认全屏快捷键；截图标记时也可能需要手动按 Link 中设置的收放键。

没有画面时，先关闭 OBS、RECentral、会议软件和浏览器采集页面，再检查 HDMI 信号、HDCP、接口和驱动。

怀疑重复帧时持续移动游戏视角 5～10 秒：接收 200 FPS、画面变化≈60 FPS、重复采样 70%，表示采到的内容每秒约变化 60 次。变化率来自叠加光标前的网格采样，静止画面会正常重复、小变化可能漏检、噪点可能抬高变化率，不能单独判定采集卡造假。新视频呈现按采集序号计数，重绘还包含光标/HUD 更新；累计帧数等可在“采集诊断详情”查看。

配置保存在程序目录。升级时保留 pointer.ini、profiles 文件夹；使用自定义光标时也保留 custom_cursor.png 和 custom_cursor.ini。

Android 系统光标（启用 Android 工具的完整版提供此页面）：
1. 在手机开发者选项另外开启“USB 调试”，用数据线直连电脑并解锁。点击刷新，待授权时在手机允许 USB 调试，再刷新选定手机并检查。手机接入 P4 时可用 Android 11+ 无线调试；配对地址和连接地址不同，先配对再连接。
2. 检查手机会显示 ROM 光标支持为允许、关闭或未知。开启先备份原设置；Android 15+ 且 ROM 允许时使用用户开关，无需写调试强制属性。其它情况尝试强制开启，零售 ROM 可能拒绝；已有 ROOT 可先检查授权。用户开关写入和强制失败分别反馈。强制值变更后重启，用 P4 手写笔模式确认显示；持久设置保留时无需重复开启，开启配置也不保证空图标变为可见图片。
3. 换图前分析手机资源，选定实际十字或悬停圆点路径，确认手机已有图标。选择图片、热点及 16～96 dp 大小，生成并导出模块，或应用到手机。普通覆盖需允许公开覆盖；Magisk 安装需 ROOT，安装后重启检查。默认空图标没有图片可替换。
4. 恢复原光标和恢复开启前设置分别操作。可恢复上一 Magisk 模块；取消或断线后先重新检查。诊断详情可导出记录、查看依赖许可和恢复资料。
刷新结果会区分未发现、待授权和离线；诊断详情保留 ADB 列表原文。没有弹窗且未发现手机时，检查数据线和 Windows 的 Android ADB Interface 驱动；待授权时解锁手机，必要时撤销手机的 USB 调试授权后重连。手机的 Windows USB 驱动需按厂商安装。
电脑无需预装 ADB、SDK 或 Java。Android 图片、备份和签名单独保存在当前用户目录，编辑手机图片不会改变 PC 光标。实际 ROM 的覆盖权限、挂载和显示仍需手机验收。
默认悬停图标不可见时，点击独立的「开启触摸反馈」，写入并读回当前用户的 show_touches=1，通常即时生效；用 P4 仅移动确认悬停圆点。也会显示手指触摸点。页面显示反馈状态，并提供「关闭触摸反馈」「恢复原反馈设置」。最初反馈值独立备份，重复操作和重新启动工具后仍可恢复；关闭开发者总开关可能重置反馈，需重新检查。仍需已授权 ADB，厂商拒绝写入时会显示失败；已有 ROOT 可明确授权后重试。
