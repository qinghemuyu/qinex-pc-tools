# QInEX Pointer 使用说明

QInEX Pointer 把硬件控制的手机指针画到电脑采集预览上。按「设备 → 画面 → 保存并使用」完成配置，以后在首页暂停、恢复即可。

## 启动与首次体验

将 `QInEX-Pointer.exe` 和 `使用说明.txt` 解压到同一可写文件夹，双击主程序。左侧导航包含「总览」「设备连接」「画面输出」「光标校准」「个性设置」「手机工具」六页；右上角「本页帮助」直接显示当前步骤。

侧栏底部可切换普通模式 / 二次元模式，即时生效，点击「保存」记住选择。切页、换肤和悬停带短过渡，继续点击或输入即可结束页面过渡。采集或全屏输出运行时自动停用动效，Windows 关闭动画时也会直接呈现。

想先看看效果，在设备页点击「演示指针（15 秒）」。独立窗口显示圆周移动，橙色表示按下。结束后返回真实设备显示，也可点击结束演示、关闭演示窗口或在演示窗口按 Esc。演示不更改真实设备的连接、画面、校准或正在编辑的参数，不需要先停止真实发送端。

演示验证电脑接收和绘制是否可用。实际手机是否对齐，需连接设备并检查。

## 第一步：连接设备

### P4 板子

1. 在设备页选择「P4 板子（单机 / 上位机直驱）」。
2. 查看「这台电脑的地址」，选择与 P4 通信的网络地址，点击「复制地址」。在板载页「网络 → VP 光标（PC / App）」启用 VP 光标，展开「高级」并填入电脑 IP，关闭「兼容旧版 App」和「自动发现接收端」；端口固定为 **6533**。
3. 本程序「P4 地址」填写板子的地址。暂时不知道可先留空，点击「开始连接」并移动设备鼠标。
4. 确认收到的是待使用的设备，点击「使用收到数据的这台设备」绑定，再点击「连接并继续」进入画面页。

例如电脑是 `192.168.1.20`、P4 是 `192.168.1.30`：板端目标填 `192.168.1.20`，程序的 P4 地址填 `192.168.1.30`。多个电脑地址对应不同网卡，选择 P4 能访问的那个。首次运行按 Windows 提示允许接收该网络的数据。

单机和上位机直驱模式的光标都由 P4 发送；上位机直驱模式的键鼠通过 QInEX-Link 转发。留空来源的一次接收会话只跟随首个有效发送者，换设备时重新连接，精细校准前必须绑定。

### S3 + QInEX

在本机 QInEX 中启用虚拟指针，选择 JSON v2，目标填 `127.0.0.1`、端口填 `6533`，关闭自动发现。本程序选择「S3 + QInEX（本机）」，点击「开始连接」。双方使用其他端口时，在「高级连接设置」中改成相同值。

QInEX 需要使用配套的静止保活版本；鼠标停住后继续收到状态，避免静止光标被判断为断流。

## 第二步：把指针对齐手机画面

在画面页选择显示方式。已有采集软件时继续使用覆盖模式；希望 QInEX Pointer 自己播放采集画面时选择采集输出模式；使用外部视频融合器合成手机画面与光标时选择纯色背景模式：

| 显示位置 | 适用场景 |
| --- | --- |
| 跟随预览窗口 | 适合独立预览或投影窗口，移动、缩放时指针区域一起更新 |
| 固定桌面区域 | 指针固定在桌面某块区域，预览移走后需重新框选 |
| 显示器全屏 | 采集软件在指定显示器全屏显示 |
| 采集卡全屏输出 | 本程序打开采集卡，并把视频和指针全屏显示到指定显示器 |
| 纯色背景全屏（融合器） | 本程序输出纯色和光标，融合器从另一路接入手机 HDMI 并完成色键合成 |

### 让本程序全屏播放采集画面

1. 选择「采集卡全屏输出」。
2. 在「采集设备」中选中采集卡；列表没有时点击「刷新设备」。同名设备会显示序号，程序以设备身份而非序号保存。
3. 「采集规格」默认选择「自动低延迟」。设备真实支持时才会出现 60、120、144、165、240 帧档；需要指定像素格式或 59.94 / 119.88 等精确时序时，勾选「精确规格」后选择完整条目。
4. 选择输出显示器。双屏默认推荐非主屏；保存过的显示器不在时会保持未选择，不会悄悄输出到另一块屏。
5. 保持默认同步可获得稳定无撕裂画面。更重视即时响应时可勾选「极限低延迟」；系统支持时会立即呈现，快速移动画面可能撕裂。
6. 点击「启动全屏」。程序在收到第一帧后进入全屏；打开中、等待 HDMI 信号、重连和错误原因会显示在画面页。
7. 全屏底部 HUD 分行显示接收 FPS、画面变化估算、重复采样比例、新视频呈现 / 重绘 FPS、软件耗时和帧间隔等数据。默认按 **F7** 显隐 HUD、按 **F8** 调整范围、按 **F11** 或 `Esc` 返回设置；三组按键可在设置页分别修改，HUD 会显示当前绑定。右键菜单和托盘也可操作。上位机直驱模式独占输入时，QInEX-Link v0.1.13+ 会读取并放行当前自定义绑定。
8. 将设备指针移到四角和中心，确认位置、方向和移动轨迹后保存。

精确规格不会自动降档。如果采集卡拔插、驱动更新或换接口后不再提供该规格，程序会要求重新检测和选择。画面页用一行「规格」摘要显示当前模式、实测帧率和采集引擎；协商结果、掉帧信息与错误原因放在「采集诊断详情」。HUD 的软件帧到屏耗时只覆盖采集帧进入本程序至成功 Present 的 PC 链路，不等于 HDMI 输入到显示器发光的端到端延迟。高帧档还需要 USB 链路、电脑和输出屏共同支持。

怀疑重复帧时，持续移动游戏视角 5～10 秒，对照下列指标；不要只看静止菜单或移动 PC 光标。

| HUD 指标 | 如何理解 |
| --- | --- |
| 接收 FPS | 本程序取得多少帧；重复画面仍计数 |
| 画面变化≈ / 重复采样 | 叠加光标之前固定 RGB 网格的变化率与相同采样占比，约每秒更新 |
| 新视频呈现 / 重绘 | 前者按采集帧序号统计首次 Present，后者还包括光标和 HUD 重绘；两者均不是内容去重后的真实 FPS |
| 连续相同 | 已交付样本持续没有采到画面变化的时长 |
| 帧间隔 P95 / 峰值 | 接收节奏是否稳定；峰值明显偏大表示曾有长间隔 |
| 时间戳重复 / 倒退 | 当前分析段的累计时序异常，缺少时间戳会明确显示不可用 |
| 入口跳过 | 程序忙时单槽邮箱被新样本覆盖的累计数量，和采集卡驱动掉帧不是同一指标 |

例如接收 200 FPS、画面变化≈60 FPS、重复采样 70%，表示这些样本每秒约有 60 次内容变化。静止画面本来就会重复，局部小变化可能漏检，噪点可能抬高变化率；这些数据用来定位问题，不能单独证明采集卡造假、插帧或手机游戏真实 FPS。累计帧数、最长相同时间和完整说明在「采集诊断详情」中；重连或格式变化后重新统计。

如果设备能识别但不公开规格列表，「采集规格」会显示「自动兼容（使用驱动当前格式）」。保持该项并启动即可，程序会绕过规格列表，直接尝试驱动当前格式；这种情况下无法预先选择精确档位，成功出帧后查看规格摘要，需要完整结果时打开「采集诊断详情」。

程序会优先使用标准采集方式；设备打不开或一直没有首帧时，会自动尝试 DirectShow 兼容模式，不需要手动选择品牌或采集引擎。当前引擎显示在规格摘要中。两种方式都没有画面时，先关闭 OBS、RECentral 等可能正在使用采集卡的软件，再检查 HDMI 信号、HDCP、驱动和采集卡指示灯。

退出全屏会保留采集连接，再点「进入全屏」即可恢复；「停止采集」才关闭采集卡。使用当前暂停快捷键（默认 **Ctrl+Alt+F10**）只会暂停指针，画面继续播放。视频中断时指针自动隐藏，程序保留 UDP 设备连接并尝试重连。当前只输出视频，不会更改 Windows 音频设备。

基础模式会按采集帧比例居中显示，程序生成的黑边不参与指针映射。输入帧自身含黑边、需要裁剪或旋转时使用高级模式；画面与光标会在同一 GPU 输出表面共用相同的裁剪、旋转、镜像和缩放，指针移动会独立唤醒绘制，不必等待下一帧视频。

### 给视频融合器输出纯色和光标

此模式把电脑的一路显示输出作为色键图层。QInEX Pointer 只输出纯色背景和光标；手机 HDMI 画面接到融合器的另一路输入，色键抠除和最终画面合成都由融合器完成。该模式不打开、不占用采集卡，可与采集卡录制、环出或其它采集软件同时使用。

1. 选择「纯色背景全屏（融合器）」。
2. 选择连接到融合器的输出显示器。保存过的显示器不在线时，程序不会改投其它屏幕。
3. 选择绿幕、蓝幕、黑场或自定义背景色，并在融合器上设置相同的色键颜色。背景色不要与光标颜色相同或过于接近。
4. 点击「启动融合输出」。该模式不等待视频首帧，会直接进入纯色全屏。
5. 底部 HUD 默认显示 Present 速率 / 帧数、输出刷新率和指针数据状态。它不会显示采集 FPS 或采集延迟，因为此模式没有采集链路。默认按 **F7** 隐藏或重新显示。
6. 对照融合器的最终合成画面，默认按 **F8** 调整光标范围：框内拖动可平移，拖边缘或四角可缩放，`Enter` 应用，`Esc` 取消。
7. 默认按 **F11** 或 `Esc` 返回设置，也可使用右键菜单或托盘。HUD、范围和退出键可在设置页修改；上位机直驱模式独占输入时，QInEX-Link v0.1.13+ 会读取并放行当前自定义绑定。

HUD 会随这路 HDMI 信号进入融合器。正式色键合成需要干净纯色背景时，先使用当前 HUD 快捷键（默认 **F7**）隐藏；右键菜单也可切换。使用当前暂停快捷键只会隐藏光标，纯色背景与 HUD 显示状态保持不变。保存后，下次可恢复输出显示器、背景色和光标范围。

**完整手机画面都能看到时：**

1. 「手机画面范围」选择「完整手机画面可见（基础）」。
2. 点击「框住完整手机画面」，移动和调整边框，贴合完整手机四边，排除黑边和工具栏。
3. Enter 确认，Esc 取消。跟随模式下边框需完整放在预览客户区；对全屏目标单独框选后会使用固定桌面区域。
4. 将设备光标移到四角和中心，检查方向、位置、移动行程。确实检查后勾选「我已在手机画面检查四角、中心和移动方向」，点击「保存并使用」。

基础模式无需填写帧尺寸或黑边百分比。如果预览裁掉了手机边缘，使用下方高级模式；剩余区域不能代表整个手机。

窗口最小化时指针隐藏；「仅在预览前台时显示」会在切到其他程序时暂时隐藏。窗口关闭后点击「刷新窗口」重新选择。含固定工具栏或侧栏的预览，在改变布局或尺寸后重新框选并检查。可优先使用采集软件独立的视频预览窗口。

## 日常使用与保存

首页显示当前设备、预览和显示状态。

| 操作 | 结果 |
| --- | --- |
| 暂停显示 / 恢复显示 | 隐藏或恢复指针；设备数据继续接收，恢复使用当前状态 |
| 设备页「断开设备」 | 停止真实设备接收并隐藏指针 |
| 画面页「退出全屏」 | 返回控制窗口，采集连接继续保持 |
| 画面页「停止采集」 | 关闭视频采集；指针设备接收继续保持 |
| 融合输出中暂停指针 | 隐藏光标，纯色背景继续全屏输出 |
| 融合输出中退出全屏 | 返回控制窗口；不影响指针设备，也不涉及采集卡启停 |
| 最小化设置窗口 | 继续显示指针，可从托盘恢复窗口 |
| 主窗口右上角 X / Alt+F4 | 隐藏到托盘，保留页面草稿；指针和已启动的采集／融合输出继续运行 |
| 托盘右键 →「退出程序」 | 结束运行；尚有未保存修改时提示处理 |

点击任务栏右下角的 QInEX Pointer 托盘图标可恢复窗口；图标也可能在「显示隐藏的图标」区域。首次隐藏会提示恢复方式。隐藏窗口会保留本次编辑内容，退出程序前仍需保存。

设置页的「自定义快捷键」可分别设置暂停 / 恢复、HUD、范围校准和退出全屏，默认依次为 **Ctrl+Alt+F10**、**F7**、**F8**、**F11**。普通字符键需要搭配 Ctrl、Alt 或 Shift；暂停、HUD 和范围键可以关闭，退出键必须保留。`Esc` 和固定后台逃生键 **Ctrl+Alt+F12** 始终可退出全屏，不能分配给其它动作。快捷键属于整个程序，切换设备或打开场景不会改变。上位机直驱模式独占输入时，QInEX-Link v0.1.13+ 会读取当前自定义绑定并转交给 Pointer；包含 **Ctrl+Alt+Q** 的组合始终保留为 Link 的紧急释放键。

设置页提供箭头、圆点、十字、圆环、涟漪、锁定框、轨迹和自定义图片八种光标，大小可设 12～144 像素。选择自定义图片后，在棋盘格预览中拖动十字设置真正落点，滚轮可放大微调。在热点编辑器点击「保存并应用」后，图片会立即转换为透明 PNG 并与热点一起写入程序目录的 `custom_cursor.png` 和 `custom_cursor.ini`，不需等待主页「保存」。普通预览、采集全屏和融合输出使用同一热点；透明 PNG 效果最佳。升级时应一并保留这两个文件。

参数修改遵循以下规则：

- **正在编辑的参数**先成为草稿，「应用本页」或对应继续操作使其生效。
- **形状、合法大小和颜色**立即预览；快捷键在快捷键窗口确认后立即应用。热点编辑器的「保存并应用」会立即保存图片和热点；当前选中的样式、大小、颜色和快捷键要在下次启动时恢复，仍需点击主页「保存」。
- **保存**只保存已应用的配置，不断开接收；有未应用草稿时先处理对应页面。
- 底部区分「有未应用的修改」「已应用，尚未保存」「设置已保存」。跨显示器移动保留草稿。

程序目录的 `pointer.ini` 保存上次设置，`profiles/` 为明确设备分别保留画面与校准。切回已用设备恢复其配置，保存后供下次继续使用。同一板子换手机或改变板端触摸映射时，仍需重新检查。

同一设备使用不同采集卡或布局时，在设置页「保存场景…」生成独立 INI；「打开场景…」恢复该场景。打开后复核目标窗口和触点，满意再保存当前配置。备份时保留 `pointer.ini`、`profiles/` 和自行导出的场景。

默认启动后手动连接；勾选「启动时连接上次设备」并应用、保存后，下次自动连接。

## 采集卡与融合输出快捷范围校准

大多数整体偏移、行程过大或行程不足，不需要逐点截图。先启动采集卡全屏或纯色融合输出；融合模式应观察融合器最终合成画面：

1. 触发当前「调整光标范围」快捷键（默认 **F8**），画面上出现青色范围框；QInEX-Link v0.1.13+ 会在 上位机直驱模式独占输入时识别当前自定义绑定并交给 Pointer。
2. 在框内拖动可整体平移，拖动边缘或四角可调整宽高。让范围对应手机触摸坐标在采集画面或融合结果中应覆盖的区域。
3. 按 `Enter` 应用，按 `Esc` 取消。也可右键选择应用或取消。
4. 移动设备光标检查四角、中心、横竖线和对角线。满意后使用当前退出键（默认 **F11**）返回设置，点击保存。

范围调整期间由校准指引代替普通 HUD；应用或取消后恢复调整前的 HUD 显隐状态。这个操作只校准光标坐标，不改变采集视频、融合器设置或纯色背景。再次触发当前范围快捷键会从现有范围继续调整。采集卡模式应用新范围后会清空与旧范围对应的九点样本，仍可用「撤销上一步」恢复；融合模式使用独立范围，不会覆盖采集卡校准或样本。

## 有残余偏差时：九点精调

先完成画面范围、旋转和设备绑定。在手机开发者选项开启「指针位置」或可见触点显示，确认预览里能看到真实触点。使用普通光标跟随触摸。覆盖模式的预览需完整位于桌面内并避免其他窗口遮挡；采集卡全屏输出会直接冻结停稳后到达的新视频帧，不受桌面遮挡影响。板端指针偏移建议先设为零。

1. 校准页选择九宫格位置。边缘点略向内收，约离边缘一成。准备时间默认 **5 秒**，可设 3～30 秒。
2. 点击取样按钮。采集卡模式会自动恢复全屏画面，独立提示显示当前点和倒计时；将触点移到对应区域并持续按住。需要中止时使用当前退出快捷键，会取消本次取样并返回设置。
3. 准备后最多等待 **45 秒**；提示说明正在等设备数据、按下、位置停稳或预览可见。保持位置至少 **800 ms**，同时确认视频真实触点也停稳。
4. 看到「截图完成」并听到提示后再松开。程序会把全屏画面置于截图后方并回到可操作的截图界面，控制窗口不会被全屏画面挡住。上位机直驱模式使用 QInEX-Link v0.1.13+ 时会自动放行本机键鼠，转发连接继续保持；旧版 Link 不支持自动放行，请按 Link 中设置的收放键。不要在截图前停止转发。
5. 静态截图中点击真实触点中心。确认按钮会在完成标记后启用；右侧 **4× / 8×** 放大镜帮助检查，方向键每次移动**原图 1 像素**，再次点击可重新定位。「确认并记录」或 Enter 确认，Esc 取消本次取样。截图窗口会按当前显示器可用区域缩放，底部按钮始终可操作。
6. 补齐九点，点击「计算并应用校准」。结果显示最大像素误差，过大时指出优先重采的位置。
7. 点击「采一个独立验收点」，到新位置取样，再点击「检查验收点」。这个点不参与九点计算，每次重新计算后需重新采验收点。
8. 检查边缘、中心、横竖线、对角线、圆周移动及预览缩放后的落点，满意后点击「保存」。

标错一点，可选中它单独重采或「撤销上一步」。「清空采样」保留已应用校准；「恢复默认校准」保留样本，可重新计算；两项都可撤销。取消或等待超时保留已有成果。

准备和等待期间有「取消取样」。QInEX-Link v0.1.13+ 会在截图冻结后自动放行本机键鼠；准备和等待阶段仍需保持转发，让程序收到真实触点。使用旧版 Link 时，截图完成后按 Link 中设置的收放键，再操作截图窗口。

采样最大误差超过 10 像素时不应用新校准；小的拟合误差仍需独立验收。计算时使用当前实时采集画面，相同裁剪和宽高比下的分辨率变化不会误判为画面改变；裁剪、旋转、镜像或画面比例实际改变时会要求重采。勾选“已检查”或演示通过不代表程序已验证真实精度。截图、采样、撤销历史只在本次运行保留，保存的是校准结果。

## 高级画面设置：裁剪与两层黑边

选择「预览裁掉手机边缘 / 使用完整采集帧（高级）」后，覆盖模式先框选采集软件的视频显示容器；采集卡全屏输出直接使用实际视频帧。以下参数描述完整输入帧及输出时保留的区域：

| 参数 | 填写内容 |
| --- | --- |
| 完整采集帧 宽 / 高 | 覆盖预览模式填写原始视频帧，例如 1920 / 1080；采集卡全屏输出会自动读取 |
| 帧内手机 %：左 / 上 / 宽 / 高 | 手机有效内容在完整帧中的位置和尺寸 |
| 保留整帧 %：左 / 上 / 宽 / 高 | 预览保留的完整帧区域 |

两组百分比都以旋转前**完整采集帧**为基准，后两项是宽、高；完整区域为 `0 / 0 / 100 / 100`。

例如帧为 1920×1080，中央手机内容为 1920×864，上下各有 108 像素黑边。整帧等比放进 1000×400 容器时：

- 完整采集帧：覆盖预览模式填写 `1920 / 1080`；采集卡全屏输出由程序自动读取。
- 帧内手机：`0 / 10 / 100 / 80`。
- 保留整帧：`0 / 0 / 100 / 100`。
- 顺时针旋转 0°，不勾拉伸铺满。

手机实际显示约 711×320，距容器左侧约 144 像素、顶部 40 像素。预览已裁掉帧内黑边时，「保留整帧」改为 `0 / 10 / 100 / 80`，帧内手机参数保持不变。

预览额外旋转画面，就设置同一顺时针角度；镜像按旋转后显示方向设置。只有实际预览拉伸时使用「拉伸铺满」。板端触摸旋转继续在板端配置。

## 显示延迟与排查

默认延迟 0 ms。指针明显领先视频时，在设置页适当增加「显示延迟」，观察后应用；增加延迟也降低响应速度，当前不能自动精确同步视频。

先看首页的设备和显示状态，进一步信息位于设备页「诊断详情」。

| 状态或现象 | 下一步 |
| --- | --- |
| 等待设备数据 | 移动设备鼠标，核对发送端启用状态、电脑目标地址和端口；P4 确认网络可达 |
| 端口无法监听 | 关闭占用同端口的其他实例或接收程序 |
| 数据已中断 | 恢复发送端和网络；S3 确认带静止保活的配套 QInEX |
| 设备要求隐藏 | 检查发送端当前光标模式，这是发送端状态 |
| 预览最小化 / 未找到 | 恢复预览，或刷新后重新选窗口 |
| 显示暂停 | 在首页、托盘恢复，或按所设组合键 |
| 当前位置在画面外 | 复核边界、裁剪和方向 |
| 中心接近、边缘偏差大 | 先查画面范围和实际缩放，再做九点校准 |
| 缩放后错位 | 查固定工具栏、侧栏或布局改变，重新框选 |
| 取样超时 | 按提示确认新鲜数据、持续按下、视频停稳和预览可见，再重试 |

P4 普通指针通常约每 16 ms 发送一次，采样间短促按下或快速移动可能未完整呈现。协议、坐标算法和构建测试见 [README](README.md) 后部。

真实手机、P4/S3 与采集卡触点精度、输入收放体验仍需联调，真实用户可用性测试也尚未完成。录制或直播要包含指针，还需确认结果包含电脑指针叠加层。

## Android 系统光标

本节适用于启用 Android 工具的完整版。桌面版提供 PC 光标、校准、采集卡与融合输出。

在手机「开发者选项」中另外开启「USB 调试」，用支持数据传输的线直连电脑，解锁手机。打开「工具」页点击刷新；发现待授权手机时，在手机允许 USB 调试，再次刷新并选择已授权的手机，点击「检查手机」。手机接着 P4 时，可在 Android 11 及以上使用无线调试。配对地址与连接地址不同，先输入配对地址和六位配对码，再用无线调试主页的连接地址连接。

刷新后底部显示未发现、待授权或离线的具体结果；「诊断详情」保留 ADB 设备列表原文和本机服务信息。没有授权弹窗时先查看结果：待授权说明已建立 ADB 连接，解锁手机，必要时在手机撤销 USB 调试授权后重连；未发现设备时检查数据线和 Windows 设备管理器中的 Android ADB Interface 驱动，只有 MTP 文件传输设备不代表 ADB 已可用。程序内嵌 ADB 可执行文件，手机的 Windows USB 驱动仍需按厂商安装。[Android USB 连接说明](https://developer.android.com/studio/run/device)、[厂商驱动说明](https://developer.android.com/studio/run/oem-usb)。

「检查手机」同时查询 ROM 的手写笔光标资源开关，显示为允许、关闭或未知。「开启手写笔光标」先保存原设置；Android 15 及以上且 ROM 允许时，开启并读回用户开关，无需写调试强制属性。ROM 关闭支持或查询未能确认时，尝试写入强制值；部分零售系统会拒绝此属性，有 ROOT 时可明确检查授权后使用。用户开关已写入而强制失败时会保留真实结果，不表示全部修改均未执行。

用 P4 的手写笔模式移动光标确认实际显示；强制属性变更后需重启手机。持久设置保留时无需重复开启，开启配置也不保证默认空图标变为可见图片。「恢复开启前设置」恢复原值，重启后系统默认显示行为由手机决定。[AOSP 开启条件](https://android.googlesource.com/platform/frameworks/base/+/android-16.0.0_r1/core/java/android/hardware/input/InputSettings.java)。

手写笔开关已开启但默认图标不可见时，点击独立的「开启触摸反馈」。工具直接修改当前用户的 `show_touches` 并读回，通常即时生效；用 P4 仅移动、不按下，确认悬停圆点。此设置也会显示手指触摸点，可「关闭触摸反馈」或「恢复原反馈设置」。首次修改前的反馈值独立备份，重复开启和重新启动工具不会覆盖最初备份，原值缺失时恢复缺失状态。关闭开发者总开关可能会把反馈重置为关闭，需重新检查。此入口仍需要已授权 ADB，不能绕过厂商写入权限或替代资源覆盖权限。

外观替换先「分析手机资源」，再选择手机实际使用的十字或悬停圆点路径，并确认手机已显示该图标。选择预设或自定义图片，编辑热点及 16～96 dp 尺寸，生成安装包。导出模块供手机 Magisk 安装，或使用「应用到手机」选择安装方式。普通覆盖要求资源允许公开覆盖；Magisk 方式需要 ROOT，安装后重启，再检查覆盖状态和实际图片。系统默认空图标时没有图片可覆盖。

「恢复原光标」可撤销本工具覆盖，或恢复上次安装前的 Magisk 模块；手机外观和手写笔开启设置分别恢复。断线、取消或失败后先重新检查手机，不把命令完成当作已显示。诊断详情提供操作记录、依赖许可和诊断导出。

替换共用资源也会影响其它使用同种系统图标的场景。USB 未发现手机时检查调试授权及 Windows 的 ADB 接口驱动，也可使用无线连接。

ADB 和资源构建依赖已内嵌，电脑无需另装 SDK 或 Java。Android 图片、设置备份和签名保存在当前用户目录，PC 光标图片和配置仍在程序目录。实际 ROM 的权限、模块挂载和显示效果需要按手机验证。
